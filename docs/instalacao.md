# Instalação

Para rodar esse projeto, temos duas opções:

### Docker Compose

Para rodar esse projeto com docker, é nessesário ter tanto o [Docker e Docker Compose](./docker/index.md) instalados. Após a instalação, podemos rodar o comando:

```
docker compose up -d
```

Após isso os containers irão subir e teremos a aplicação rodando.

### Manualmente

Também podemos rodar o projeto localmente, porém cada parte dele deve ser feito separadamente:

#### web

#### crawler-api

#### mongodb
