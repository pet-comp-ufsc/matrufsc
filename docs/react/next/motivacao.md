# Por que NextJS?

Apesar de já termos o React na nossa stack, ela é apenas uma biblioteca de UI. Para construir um site real com React puro, você precisa gastar semanas configurando roteamento, empacotadores (Vite/Webpack), estratégias de cache, otimização de imagens e compiladores. O Next.js resolve tudo isso por padrão.

Podemos também aproveitar outras coisas que o NextJS pode nos oferecer, como:

1. **Segurança e Infraestrutura Unificada:** Com NextJS, não precisamos criar um backend separado para puxar os dados da aplicação para o frontend, eliminando complexidade do projeto. Isso também nos possibilita impedir que partes críticas do código (como chamadas de API com chaves privadas, por exemplo) sejam expostas ao cliente, nos dando mais segurança.

2. **Otimizações Automáticas:** NextJS também faz otimizações por debaixo dos panos em tempo de compilação, simplificando o desenvolvimento.

3. **Boa experiência de desenvolvimento (DX):** Pelo fato de NextJS fazer e otimizar muitas coisas por padrão, temos uma experiência de desenvolvimento melhor e uma produtividade maior. Não é raro que projetos grandes que usam React também usam NextJS.
