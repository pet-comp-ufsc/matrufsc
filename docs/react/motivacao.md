# Por que React?

React é uma biblioteca para construção de interfaces para a web. A adoção do react neste projeto se baseia em questões técnicas e não técnicas:

- **Arquitetura Baseada em Componentes:** Permite separar a interface me partes isoladas e testáveis. Isso reduz duplicação de código e facilita a manutenção por múltiplos desenvolvedores.
- **Fluxo de Dados Unidirecional:** Os dados fluem de cima para baixo (de componente pai para filhos). Isso torna o rastreamento de bugs previsível e facilita o entendimento de como as mudanças de estado afetam a inteface.
- **Ecossitema Amplo:** Além do próprio react, podemos ter uma gama de outras bibliotecas que são construidas em cima dela, como por exemplo gerênciamento de estados globais, componentes de _drag-in-drop_ e etc, facilitando o desenvolvimento.
- **Padrão de Mercado:** Além de tudo, react é uma das bibliotecas frontend mais usadas no mercado de apps modernos, por isso é interessante aprender essa tecnologia durante o desenvolvimento desse projeto.
